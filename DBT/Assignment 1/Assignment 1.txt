3. Write the SQL command to create a table Books with the following fields:
   - book_id (Primary Key, INT)
   - title (VARCHAR(150))
   - author_id (Foreign Key referencing Authors)
   - published_year (YEAR)
   - available_copies (INT)
   
Solution: 
		create table Books 
		(book_id int primary key,
		title varchar(150),
		author_id int,
		published_year year,

14. Write an SQL query to find all members who have borrowed the book with title 'Database Systems'.

Solution:

select distinct m.member_id,m.name,m.email,m.phone
from member m
join borrow_records br on br.member_id = m.member_id
join books b on b.book_id = br.book_id
where b.title = 'The Hidden Hindu';

18. Write an SQL query to list all books along with their authors' names.

Solution:

select b.title as books,
    a.name as authors
    from books b
    join authors a on a.author_id = b.author_id;

20. Write an SQL query to find all books that are never borrowed (i.e., no records in Borrow_Records).

Solutions:

select b.* 
from books b
left join borrow_records br on br.book_id = b.book_id
where br.book_id is null;

or

select * from books where book_id NOT IN (select book_id from borrow_records);

or

select * from books b
where NOT EXISTS 
(select 1 from borrow_records br where br.book_id = b.book_id);
