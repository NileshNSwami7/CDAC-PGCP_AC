1. Write a SQL query to create Employee & Department table with specific columns and constraints.
(Note- Create Table, insert data as per your Choice)

Solution:

Employee table:

	create table employee
    (emp_id int primary key,
    empname varchar(20) not null,
    empage int ,
    empsalary decimal(10,2),
    empphone bigint,
    dept_id int,
    CONSTRAINT fk_dept_id FOREIGN KEY (dept_id) REFERENCES department(dept_id));
	
Department table:

	create table department
    (dept_id int primary key,
    dept_name varchar(20) not null unique,
    city varchar(20));

15.Write a query to count the total number of employees in each department.

Solution:

	SELECT d.dept_name,count(e.emp_id) As total_employee
	from Department d
	Left Join Employee e ON d.dept_id = e.dept_id
	GROUP BY d.dept_id,d.dept_name;

16.Write a query to list departments that have no employees. & 
create a view for those salespeople who belong to the city of Mumbai. 

Solution :
	
	select d.dpt_id,d.dept_name,d.city
	from department d
	left join Employee e ON d.dept_id = e.emp_id
	where e.dept_id IS null;
	
	Create view Membai_salespeople As
	select * from Department
	where city = 'Chennai';
