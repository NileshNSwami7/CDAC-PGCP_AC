2.Write a query to find the average salary of employees in each department using GROUP BY.

	solution:
		select dept_id,avg(empsalary) as avg_salary
		from employee 
		group by dept_id;
		
		select d.dept_id,avg(e.empsalary) as avg_salary
		from department d
		join employee e on d.dept_id = e.emp_id;
		GROUP BY d.dept_id,d.department;

3.Write a query to count the total number of employees in each department.

Solution:
	
	select d.dept_id ,d.departmentname,count(e.emp_id) as number_of_employee
	from department d
	left join employee e on d.dept_id = e.dept_id
	Group By d.dept_id,d.department;

4.Write a query to display departments having more than 5 employees using HAVING clause.

Solution:
	select d.dept_id,d.departmentname,count(e.emp_id) as no_of_employee
	from department d
	left join employee e on d.dept_id = e.dept_id
	group by d.dept_id
	having count(e.emp_id)>=5;

18. Write a query to calculate the total salary per department, 
but only for departments where total salary is greater than 1,00,000 (use HAVING).

Solution:
    select d.dept_id,d.departmentname,sum(e.empsalary) as total_salary
	from department d
	join employee e on d.dept_id = e.dept_id
	group by d.dept_id,d.departmentname
	having sum(e.empsalary) > 100000;

20. Write a query to count the number of departments having the same location.

Solution:
  
	select city, count(*) as no_of_city
	from department d
	GROUP BY city
	having count(*)>1;
